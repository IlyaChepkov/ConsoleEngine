# ConsoleEngine
Reactive engine for C# console applications

Это текстовый консольный движок для создания пошаговых игр в консоли C#. Данный движок является реактивным - он не выполняется постоянно (как например в Unity или MonoGame), а реагирует на нажатие клавиш на клавиатуре. Он не позволяет делать игры в реальном времени, но дает функционал для создания пошаговых текстовых игр.
